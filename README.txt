SHILAT - PERSONAL PORTFOLIO WEBSITE
=====================================

Live website:
https://shilat-portfolio.netlify.app/

Project files:
- index.html  : The single-page portfolio website
- style.css   : Website styling and layout
- script.js   : JavaScript interactions and behavior
- images/     : Images and icons used by the website
- package.json: Project metadata, if included

Technologies:
- HTML
- CSS
- JavaScript
- Bootstrap

How to view the website:
Open the live website link above in a web browser.

How to run locally:
Open index.html in a web browser. An internet connection may be needed
for Bootstrap and other libraries loaded from CDNs.

Deployment:
The website is hosted on Netlify.
